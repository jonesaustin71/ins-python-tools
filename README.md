# ins-python-tools

Host-side utilities for decoding logs, running offline fusion, and plotting handling metrics.

```
docs/        Usage docs, API reference, troubleshooting
examples/    Short notebooks/scripts showing end-to-end workflows
scripts/     CLI helpers (decode, plot, batch processing)
src/ins_tools/  Package code (parsers, fusion helpers, viz)
tests/       Pytest-style regression + lint configs
data/        Small sample logs for tests/demos
```
